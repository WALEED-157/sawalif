# 💬 سوالف العائلة

دردشة آمنة للعائلة والأطفال: رسائل، ملصقات، صور وفيديو وصوت **تنشاف مرة وحدة**، قروبات، وألعاب خفيفة.
الأهل يشوفون كل محادثات أطفالهم، والأطفال ما يضيفون أحد إلا بموافقة أهل الطرفين.

يشتغل كتطبيق ويب (PWA) على الآيفون والأندرويد. يتثبّت على الشاشة الرئيسية ويفتح مثل أي تطبيق.

---

## 🧱 كيف يشتغل؟

| الجزء | وين |
|---|---|
| واجهة التطبيق (هذي الملفات) | **GitHub Pages**: مجاني ويعطيك رابط |
| الحسابات + الرسائل + الملفات | **Supabase**: مجاني (500MB قاعدة بيانات + 1GB ملفات) |

الصور والفيديو والصوت تنحذف تلقائياً بعد **7 أيام** عشان التخزين ما يكبر.

---

## 🚀 خطوات التركيب (تقريباً 15 دقيقة)

### 1) إنشاء مشروع Supabase
1. ادخل [supabase.com](https://supabase.com) وسوّ حساب مجاني، بعدها **New project**.
2. اختر اسم وكلمة مرور لقاعدة البيانات، والمنطقة الأقرب لك (مثلاً Frankfurt أو Mumbai).

### 2) تركيب قاعدة البيانات
1. من القائمة الجانبية افتح **SQL Editor**، بعدها **New query**.
2. انسخ محتوى ملف [`supabase/schema.sql`](supabase/schema.sql) كامل، الصقه، واضغط **Run**.
3. غيّر **رمز التسجيل**، وهو الرمز اللي تعطيه للعوائل عشان يقدرون يسجلون (بدونه أي أحد عنده الرابط يقدر يسجل):
   ```sql
   update public.app_config set signup_code = 'رمز-سري-تختاره';
   ```

### 3) إعدادات الدخول
من **Authentication، بعدها Sign In / Providers**:
- ✅ فعّل **Allow anonymous sign-ins**. هذا ضروري لدخول الأطفال بكود QR.
- في **Email**: إذا ما تبي الأهل يأكدون الإيميل، أطفِ **Confirm email** (أسهل للعائلة).

### 4) ربط التطبيق بـ Supabase
1. من **Project Settings، بعدها API** (أو **API Keys**) انسخ:
   - **Project URL**
   - مفتاح **anon / publishable**. هذا آمن يكون في الكود. ⚠️ **لا** تستخدم مفتاح `service_role` أو `secret` أبداً.
2. افتح [`js/config.js`](js/config.js) وحطها:
   ```js
   SUPABASE_URL: 'https://xxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJhbGciOi...',
   ```

### 5) النشر على GitHub Pages
1. سوّ مستودع (repository) جديد في GitHub وارفع كل الملفات.
2. من **Settings، بعدها Pages**: اختر **Deploy from a branch**، بعدها `main` و `/ (root)`، واضغط **Save**.
3. بعد دقيقة يطلع لك الرابط: `https://اسمك.github.io/اسم-المستودع/`

### 6) آخر خطوة في Supabase
من **Authentication، بعدها URL Configuration** حط رابط GitHub Pages في **Site URL** وفي **Redirect URLs**.
هذا عشان روابط تأكيد الإيميل واستعادة كلمة المرور ترجع للتطبيق.

## 👨‍👩‍👧 طريقة الاستخدام

1. **الأب (أو الأم)** يفتح الرابط، بعدها **حساب جديد** بالإيميل، بعدها **عائلة جديدة** (يحتاج رمز التسجيل).
2. من صفحة **العائلة** ينسخ **رمز الانضمام** ويعطيه للزوج أو الزوجة، وهو يسجل بإيميله ويختار **انضم لعائلتي**.
3. **إضافة طفل**: من صفحة العائلة اختر **＋ إضافة طفل**، ويطلع كود QR.
4. **الطفل** يفتح كاميرا جواله ويمسح الكود، ويدخل مباشرة بدون إيميل أو كلمة مرور.
5. **تثبيت التطبيق**:
   - آيفون: Safari، بعدها زر المشاركة ⬆️، بعدها **إضافة إلى الشاشة الرئيسية**
   - أندرويد: Chrome، بعدها ⋮، بعدها **تثبيت التطبيق**

### إضافة صديق من عائلة ثانية
- كل شخص له **رقم تعريفي** من 6 أرقام (في صفحة الأصدقاء).
- الطفل يكتب رقم صديقه، والطلب يحتاج موافقة **أهله وأهل صديقه** قبل ما يقدرون يتكلمون.

### أدوات الأهل
- 👁 قراءة كل محادثات الطفل (الخاصة والقروبات)، وشوف صوره وفيديوهاته خلال 7 أيام
- 🗑️ حذف أي رسالة
- ⚠️ تنبيهات تلقائية لما تنرسل أرقام جوالات أو روابط أو حسابات سناب وانستا، أو كلمات تحددونها
- 🔒 إيقاف الإرسال مؤقتاً
- 🌙 وقت راحة (مثلاً من 9 بالليل لين 6 الصبح، بتوقيت السعودية)
- 📴 تسجيل خروج جهاز الطفل
- إلغاء أي صداقة

## 📁 الملفات

```
index.html            الصفحة الرئيسية
css/style.css         التصميم
js/config.js          ⚙️ إعدادات Supabase (عدّل هذا)
js/main.js            الشاشات: الدخول، المحادثات، الأصدقاء، العائلة
js/chat.js            شاشة المحادثة: رسائل، ملصقات، صوت، صور، فيديو
js/games.js           الألعاب: إكس أو، أربعة بالصف، حجرة ورقة مقص، الذاكرة
sw.js                 للتثبيت على الجوال
supabase/schema.sql   قاعدة البيانات وقواعد الحماية
```

## 🔐 الحماية
كل الصلاحيات مطبّقة **داخل قاعدة البيانات** (Row Level Security)، مو بس في الواجهة. يعني حتى لو أحد عبث بالكود ما يقدر:
- يقرأ محادثات مو عضو فيها (إلا الأهل لأطفالهم)
- يكلم أحد مو صديقه
- يفتح صورة "مرة وحدة" مرتين
- يتجاوز إيقاف الإرسال أو وقت الراحة

## ⚠️ حدود حالية
- **التنبيهات** تشتغل والتطبيق مفتوح أو في الخلفية. تنبيهات Push الكاملة (والتطبيق مقفل) تحتاج خطوة إضافية لاحقاً.
- مشروع Supabase المجاني **يتوقف** إذا ما أحد استخدمه أسبوع كامل، ويرجع بضغطة زر من لوحة Supabase.
- منع تصوير الشاشة غير ممكن في تطبيقات الويب، لكن "المرة الوحدة" مضمونة من السيرفر.
- المكالمات الصوتية والمرئية: المرحلة الجاية.
